Hotel Reservation System

A Java-based hotel reservation system developed as part of my Java Programming Internship at CodeAlpha.

About the Project

This project provides a simple way to manage hotel reservations through a structured Java application. It focuses on handling guest details, room availability, bookings, and reservation management.

Features

* Room availability management
* Guest details
* Room booking
* Reservation management
* Simple and interactive user interface

Technologies Used

* Java
* Java OOP concepts
